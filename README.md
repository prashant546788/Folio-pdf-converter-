## GitHub Pages

To publish this project with GitHub Pages:

1. Open the repository’s **Settings** tab.
2. In the sidebar, select **Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose the branch and folder containing the site files, then click **Save**.
5. After deployment completes, visit the site URL shown in the Pages settings.

Changes may take a few minutes to appear. See GitHub’s [Quickstart for GitHub Pages](https://docs.github.com/en/pages/quickstart) for more information.
